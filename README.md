One word an agent says when it has no idea what to do: **hallucinating**.

When an agent is completely lost it rarely admits it in plain language — it
keeps going and confidently invents the answer instead. "Hallucinating" is the
honest one-word confession of that moment: the machine's own vocabulary, funny
on its own, and it lands at a glance. One word, nothing attached.

## Run it

```sh
node main.ts
```

The program writes the word to `/output/entry.txt` (or to `$OUTPUT_DIR/entry.txt`
for a local dry run).
